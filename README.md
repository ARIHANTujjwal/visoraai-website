# VisoraAI Website

Static website for VisoraAI, an assistive AI vision prototype that turns printed text into speech using camera-based OCR, image processing, and text-to-speech.

## Files

- `index.html` — main website
- `styles.css` — responsive styling
- `script.js` — mobile navigation and scroll animations

## Deploy on Vercel

1. Push these files to the `main` branch of `ARIHANTujjwal/visoraai-website`.
2. Go to Vercel and import the GitHub repository.
3. Framework preset: Other / Static / No Framework.
4. Build command: leave blank.
5. Output directory: `.`.
6. Install command: leave blank.
7. Deploy.
8. Add `visoraai.com` as the primary domain.
9. Redirect `visoraai.net` and `visoraai.org` to `visoraai.com`.

## Notes

This website presents VisoraAI as a prototype/research project, not as a finished medical device or a guaranteed perfect OCR system.
