Mission

Making printed information easier to access.

VisoraAI combines real-time camera input, text-region detection, image enhancement, OCR confidence filtering, and text-to-speech. The goal is to create a practical reading workflow where the system does more than scan: it guides the user toward a clearer image before speaking the result.

How it works

From camera frame to spoken text.

VisoraAI uses a layered pipeline so OCR receives the cleanest possible view of the text.

01

Camera input

A webcam or prototype camera captures live frames of the page or printed material.

02

Page detection

The system finds the page region first, reducing background distractions before OCR begins.

03

Text block detection

OpenCV morphology identifies the full readable text block instead of relying on the full camera image.

04

Image enhancement

The crop is upscaled, contrast-enhanced, denoised, and sharpened to improve character readability.

05

Burst capture

Multiple frames are checked for blur and glare, then combined to reduce random noise.

06

OCR to speech

Recognized text is cleaned, filtered, split into chunks, and converted into spoken audio.

Technology

Built around computer vision and assistive feedback.

CV

Computer Vision

OpenCV handles camera frames, page masks, text-block crops, blur scoring, glare detection, and visual preprocessing.

OCR

Text Recognition

The OCR path uses a custom recognition pipeline with Tesseract fallback and confidence-based filtering.

TTS

Speech Output

Recognized text becomes spoken audio, while guidance messages help the user adjust distance, angle, and stability.

AI

CRNN Research

Experimental OCR research explores a convolutional recurrent neural network with CTC-style decoding.

Research & Development

Testing OCR under imperfect conditions.

Real-world OCR is hard because the image can be blurry, tilted, overexposed, or partially framed. VisoraAI’s development focuses on image quality checks, burst processing, synthetic OCR data, and Character Error Rate evaluation.
