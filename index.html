Assistive computer vision

Reading printed text through sound.

VisoraAI is a camera-based reading prototype that uses computer vision and OCR to detect printed text and read it aloud for visually impaired users.

The product idea is intentionally simple.

Many everyday materials still assume the reader can clearly see the page. VisoraAI explores a quieter interaction: point a camera at printed text, let the system locate what matters, and hear the result aloud.

The site is structured like a project case study, not a generic AI landing page. Each part of the system has its own page so the technical story can grow as the project develops.
